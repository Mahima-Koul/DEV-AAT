# Garbage Collection & Solid Waste Management in India
## Data Exploration and Visualisation Project

**Tools:** Python, pandas, NumPy, Matplotlib, Seaborn, Google Colab

## Datasets
- CPCB State-wise Waste Data: https://cpcb.nic.in/annual-report.php
- Swachh Survekshan City Scores: https://sbmurban.org

## How to Run
1. Open `Solid_Waste_EDA.ipynb` in Google Colab
2. Run all cells in order

## Key Findings
- National treatment efficiency: 53.95% (mean)
- 66.2% of waste scientifically treated in 2020-21
- Best city: Indore (Score: 7140) | Lowest: Kolkata (Score: 3890)
